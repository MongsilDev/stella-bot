# 스텔라봇 (stella-bot)

Discord 채널 1개에서 한국어와 일본어 사용자가 자유롭게 대화하도록 실시간 상호 번역을 해주는 봇.
번역문은 원 작성자의 닉네임과 아바타로 표시되고, 답장 관계와 수정, 삭제가 번역문에 그대로 반영된다.

## 실행 방법

1. `.env.example`을 `.env`로 복사하고 값을 채운다
2. 의존성 설치: `pip install -r requirements.txt`
3. 실행: `python main.py`

봇에게 대상 채널의 메시지 보기, 메시지 기록 보기, 웹훅 관리, 반응 추가 권한이 필요하다. 번역에 실패하면 원문에 ⚠️ 반응을 단다.

다른 봇이 보낸 메시지는 기본으로 건너뛴다. 봇 메시지도 번역하려면 `.env`에 `ALLOW_BOT_MESSAGES=1`을 넣는다.
